# Day 4 – SQL Basics

This task is part of **Day 4** of the Zeroes to Heroes challenge and focuses on understanding the fundamentals of SQL.

In this exercise, basic SQL operations were practiced using a simple `users` table. The task includes creating a table, inserting records, retrieving data, applying conditions, updating values, and deleting records. Additional queries were used to sort data and filter records based on email domains.

## Operations Covered
- Creating a table using CREATE TABLE  
- Inserting records with INSERT  
- Fetching data using SELECT  
- Filtering records using WHERE  
- Updating data using UPDATE  
- Deleting records using DELETE  
- Sorting results using ORDER BY  
- Filtering emails using LIKE  

The queries were executed using an online SQL compiler for learning and practice purposes.

This task helped in building a clear understanding of how databases work and how data is managed using SQL queries.
