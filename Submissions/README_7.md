# Day 7 – Debugging & Code Understanding

Day 7 was about learning how to debug and understand JavaScript code instead of writing everything from scratch.

The task involved fixing a broken even–odd checker program. The main issues were improper data type handling and an incorrect conditional statement. After resolving these, the program now works as expected and handles invalid inputs as well.

This activity reinforced the importance of reading code carefully, understanding logic flow, and applying correct syntax while debugging real-world problems.
